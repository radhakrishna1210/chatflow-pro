# Audit: ai-automation (workflows, AI features, public widgets, sequences engine)

Tests: backend `npm test`: 538/538 passing (run after all backend fixes except the last test file, which passes on its own: 5/5). `npx vite build` passes.
Browser checks (Playwright against :5173): Automation → Workflows (create with the canvas palette, switch to list, add and remove nodes, validation errors, save, test-run, run history), Widgets (create, editor, install code), Sequences (create, save), AI Chatbots (modify, delete, new). The backend restarted often while other auditors edited files, so some runs saw proxy 500s. I re-ran those and confirmed the endpoints with curl.

Verified OK: the "fully compromised model cannot reach a write" guarantee holds. The copilot only proposes writes; confirm re-validates through scoped services and requires CLIENT. No model output in the frontend is rendered as HTML (no dangerouslySetInnerHTML or links in Copilot/SiteAssistant/AIOnboardingCard). The widget loader uses textContent throughout, and primaryColor is validated as a hex colour. The public config exposes no tokens. Widget keys are 96-bit random. Workspace-scoped AI routes (ai-agent, ai-agents, widgets, workflows, automation, intents, sequences, copilot, agent) all sit behind workspaceContext, so the VIEWER/AGENT write floor applies to them. When the Gemini key is missing, workflow preview, site assistant and copilot degrade to their fallbacks.

## Outside scope (noticed, not fixed)
- `src/services/customizeBusinessBugFixes.test.js` "Bug 9: DealStageHistory records custom stage keys" was failing during a mid-audit full run ("Unknown pipeline stage CUSTOM_DEMO_STAGE") after another auditor's deals.service.js change. It passed in the final full run.
- `middleware/rateLimit.js`: in non-failure mode the subject bucket is only enforced on the *next* request (peek), not on the hit that crosses the limit. This is minor.
- `services/outgoingWebhook.service.js` `isPrivateAddress` has the same IPv6 gaps as AA-2: no NAT64, 6to4 or hex-mapped handling, and no CGNAT/benchmark ranges. It could reuse `ipIsPublic` / `safeLookup` from lib/siteCrawler.js.
- The Vite proxy returned bare 500s during backend restarts, which made browser runs noisy.
