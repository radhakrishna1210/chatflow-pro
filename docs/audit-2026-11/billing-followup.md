## Notes / not done
- `RAZORPAY_WEBHOOK_SECRET` is env-only. It is not added to `MANAGED_SETTING_KEYS` (config/settingsStore.js), so it cannot be set from the admin settings screen the way the key id and secret can. To add it, put the key in that list and in the admin UI (owner: admin/settings).
- The server's LOW/EMPTY status and `messagesRemaining` (wallet.service.js `walletStatus`) still use `costPerMessage` × 100 as the low threshold. Only the displayed runway was changed. `messagesRemaining` is no longer rendered by the banner, but is still returned by the API.
- The webhook does not create a wallet credit for a payment whose order is not one of ours (no `notes.workspaceId`), for example a payment-link payment. These are acknowledged and logged.
- Add-on and plan webhook credits don't send an in-app notification (their verify paths don't either). Wallet top-ups do, same as verify.
