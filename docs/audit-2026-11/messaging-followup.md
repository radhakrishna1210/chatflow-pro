# messaging-followup audit

This covers the six items handed over from the messaging audit, plus the items the coordinator added later: public webhook SSRF, the per-key API rate limit, member-removal cleanup, the integrations OAuth CSRF, impersonation sessions, the rateLimit off-by-one, and the outgoing-webhook guard.

## Decisions worth knowing
- **"there" fallback:** kept only for `{{1}}` (documented greeting-name convention). Inbox and API sends refuse a missing `{{2}}`+. The campaign "approved sample for unmapped `{{2}}`+" rule was not changed. It is documented in `lib/templateParams.js`, but it does send every recipient the sample value. Product should decide whether to require a mapping.
- **Default country:** no workspace setting exists. The country comes from the sending number, with +91 as the fallback. A workspace country field would be the cleaner long-term source.
- **OAuth binding:** I used an authenticated "complete" step rather than the Google-login cookie nonce. These flows always start from a signed-in user, and the cookie only works when SPA and API share a hostname (the cookie pattern disables itself otherwise).
- **The public API now creates contacts** for new recipients, and applies the plan contact limit when it does.

## Outside my scope (noticed, not fixed)
- `services/apikeys.service.js` (~l.440–530, API Playground send) still calls Meta directly: no credit, no inbox record, no window check. It does check template status and variables. It should delegate like `sendPublicMessage`.
- axios honours `HTTP(S)_PROXY` env. If production egress uses a proxy, the connect-time `safeLookup` applies to the proxy host, not the target. The save-time `ipIsPublic` check still applies.
- When an impersonation token expires, `api.js logout()` clears `impersonatorSession`, so the admin must sign in again instead of returning to their own session. Harmless, but could be friendlier (Dashboard banner owner).
- Opt-out rows are stored in international digits. A contact stored nationally is still protected via `contact.optedOut` (STOP sets it), but `assertNotOptedOut(contact.phoneNumber)` alone would not match it.
